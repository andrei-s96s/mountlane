# Mountlane

[English](README.en.md)

**Бесплатный файловый менеджер для дисков на macOS.** Mountlane показывает, что подключено к Mac, каким форматом отформатирован диск и можно ли безопасно записывать на него.

## Что умеет сейчас

- Просматривать подключённые APFS, HFS+, FAT32 и exFAT тома.
- Показывать формат, свободное место и реальный режим «только чтение» / «чтение и запись».
- Искать и сортировать файлы, показывать скрытые файлы, копировать путь и открывать объекты в Finder.
- Копировать несколько файлов или папок между дисками.
- Проверять свободное место до копирования.
- Обрабатывать совпадения имён: сохранить оба, пропустить или заменить после подтверждения.
- Показывать историю передач и уведомления о завершении.
- Безопасно извлекать носители.
- Работать на русском, английском или языке macOS.

## NTFS без ложных обещаний

macOS обычно открывает NTFS только для чтения. Mountlane это сразу показывает.

Если на Mac уже установлены FUSE-T и NTFS-3G, откройте NTFS-диск и нажмите **«Включить запись»**. Перед изменением Mountlane покажет предупреждение, а macOS запросит пароль администратора. Если компонентов нет, кнопка **«Подготовить NTFS»** проверит систему и откроет их официальные источники.

Mountlane не включает, не скачивает и не устанавливает драйверы. Перед записью на NTFS, который использовался в Windows, безопасно извлеките его в Windows и отключите Fast Startup/гибернацию.

## Другие форматы

Для ext4 Mountlane показывает безопасный диагностический статус. Он не включает запись через непроверенный драйвер. Для обмена файлами между Mac и Windows обычно проще всего использовать exFAT.

## Как запустить

1. Установите Xcode 16 или новее.
2. Откройте `Package.swift` в Xcode.
3. Выберите схему **Mountlane** и нажмите Run.

Минимальная версия — macOS 15. Проект ориентирован на Apple Silicon.

## Безопасность данных

- Исходные файлы при копировании не удаляются.
- Замена существующего файла требует отдельного подтверждения.
- При нехватке места копирование не запускается.
- Режим записи показывается только по данным macOS.

## Бесплатный проект

Mountlane полностью бесплатен: в приложении нет рекламы, платных функций и трекеров. В будущем возможны только добровольные пожертвования без разблокировки возможностей.
